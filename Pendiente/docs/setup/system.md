# system: configuración pendiente

Desde la raíz del repositorio, `./scripts/start-dev.ps1 -App Pendiente -Mode Live -NoBrowser` inicia la estación real con su configuración local. `-Mode Demo` inicia una demostración identificada. La validación rechaza marcadores y valores pendientes.

Las demos y pruebas mantienen sus valores sintéticos, identificados como ejemplos. La documentación y evidencia técnica copiadas describen el desarrollo anterior; no prueban vuelos, datos físicos ni conexión del nuevo dispositivo.
