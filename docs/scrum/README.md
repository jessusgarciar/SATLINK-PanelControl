# Documentación Scrum

Estas carpetas organizan los documentos del trabajo del equipo:

| Carpeta | Contenido futuro |
| --- | --- |
| `product_backlog` | Elementos del producto y su orden acordado. |
| `sprints` | Objetivos, selección de trabajo y seguimiento por sprint. |
| `reviews` | Evidencias, comentarios y acuerdos de las revisiones. |
| `retrospectives` | Observaciones y acciones de mejora del equipo. |
| `definition_of_done` | Criterios compartidos para considerar terminado un incremento. |

La estructura está preparada para que el equipo complete estos documentos. Esta etapa no define historias de usuario, estimaciones, planes de sprint ni una Definition of Done.
